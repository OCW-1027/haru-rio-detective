```
✅ Phase1 (텍스트+페어링) → A (i18n+이모지) → 영어학습탭 → 
   B (presence·typing·읽음) → C (PWA+FCM) → D (페어링리셋fix) → 
   F (자동스크롤fix) → E (PWA Install) → G (race condition fix)
```

## 6. 시리즈 11 작업 시 확립한 교훈 (반드시 준수)

신규 시리즈 추가 시:

1. **데이터 파일 작성과 엔진 함수 구현은 별개**. 둘 다 완료해야 동작.
2. **데이터만 추가하고 엔진 함수가 skeleton 상태**면 챕터 그리드 빈 채로 silent failure (콘솔 에러 없음).
3. **작업 단계**:
   - ① placeholder skeleton 작성
   - ② 데이터 파일 작성
   - ③ 엔진 함수 mirror (weather/math 패턴 정밀 복제)
   - ④ 브라우저 검증 (typeof XX_STORY / typeof buildXXGrid / typeof XX_CASE_IMAGES 콘솔 검증)
   - ⑤ 다음 사건 추가
4. **각 단계 후 반드시 콘솔 검증**.


## 11. ⚠️ 주의사항 (중요)

### 11-1. 채팅 코드 건드리지 말기
이번 작업은 게임 콘텐츠 추가. 채팅 시스템(chat-*.js, manifest.json, sw.js, functions/, icons/)은 **건드리지 않음**.

### 11-2. 자녀가 사용 중이라는 점 인지
자녀가 이미 ハルゲーム 사용 중. 신규 시리즈 추가 시:
- main 브랜치 직접 push해도 OK (게임 시리즈 추가는 기존 시리즈 영향 없음)
- 다만 검증 후 push (silent failure 방지)
- 자녀가 새 시리즈 자동으로 보게 되니 「깜짝 선물」 패턴

### 11-3. detectives-A.js·B.js 패턴 분석 필요
시리즈 3은 detectives-A.js 골격이 있으니, 새 시리즈도 그 패턴 따를지 별도 .js 파일로 만들지 결정.

시리즈 10·11은 weather-learn.js·math-learn.js로 별도 파일. 신규 시리즈도 같은 방식 권장.

### 11-4. 컨텍스트 절약
새 채팅에서 시작하면 이번 채팅의 채팅 시스템 컨텍스트가 없음. 
- 이는 의도된 것 (게임 콘텐츠 작업에 집중)
- 다만 채팅 시스템 정보가 필요하면 메모리(userMemories)에서 자동 로드됨
